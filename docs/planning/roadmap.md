# Prom::Enter 개발 계획

[문서 안내](../README.md)

기준일: 2026-11-04. 저장소의 실행 코드와 보존된 스토리·캐릭터 기획을 기준으로 합니다. 외부 원문의 최신 변경은 별도 확인이 필요합니다.

이 저장소에서 실제 게임을 완성한다. 목표 경험은 **후보 면담 → 신입 선발 → 기존 3명과 팀 결성 → 24개월의 활동·대화·위기 → 누적 선택에 따른 결말**이다. 세부 수치·분기는 [기획 확인사항](../../storyline/05-open-questions.md)의 합의가 필요하다. 아래 우선순위와 완료 기준은 현재 코드에 근거한 개발 제안이며 새로운 게임 규칙을 확정한 것은 아니다.

## 판단

AI의 입력 해석 → 서버 판정 → 인물별 문맥 → 대사 생성 → 검증 → 저장은 연결돼 있다. 기존 네 사건의 축약 데모에 더해, 서버의 후보 면담·선발·1~6개월차 프로토타입이 연결됐다. 별도의 브라우저 데모는 도입·면담·영입·첫 달 계획을 지원한다. [Part 1–2 구현 범위](../development/part2-prototype.md)와 [최소 기획 결정](../../storyline/06-minimal-decisions.md)을 함께 따른다. **모델 연결을 마친 상태에서, 전체 게임을 진행시키는 대화·관계·서사 기능을 완성해야 하는 단계**다. 현재 테스트 통과만으로 전체 게임의 재미·캐릭터 일관성·자연어 판단 품질이 확인되지는 않는다.

### 대화와 진행을 연결할 때 주의할 점

- 현재 1:1 대화에서 게임 행동·보상 판정을 비우는 것은 명시된 동작이다. 관계 변화나 선발 면담을 추가할 때, 1:1이 어떤 효과까지 낼 수 있는지 먼저 계약을 정한다.
- 의미 기준을 기록하는 것과 성공·실패에 사용하는 것은 별개다. 예를 들어 “준비 상태를 살펴보자”를 이해해도, 현재 예능 결과는 훈련 이력 등 기존 resolver 규칙으로 결정된다.
- 숨겨진 지식을 공개할 함수가 있다고 실제 플레이에서 공개되는 것은 아니다. 공개 사건·조건·청중·기록이 함께 연결돼야 한다.
- 새 관계 상태·화자 ID·행동 대상·면담 진행을 추가하면 [프런트엔드 연결 명세](../development/frontend-integration.md)와 [types.ts](../../frontend/src/types.ts), 이전 저장 호환을 같은 작업에서 맞춘다.

## 권장 개발 순서

1. **첫 면담부터 1개월차 종료까지 완성한다.** 기존 멤버·후보 소개, 후보별 대화, 한 명 선발, 팀 결성, 인물별 상태, 첫 활동과 관계 반응을 실제 게임 경로로 연결한다. 현재 연결된 서버 프로토타입과 브라우저 데모를 바탕으로 남은 상태·관계 연결을 보완한다.
2. **개인 사건 하나를 끝까지 연결한다.** 관계 변화 → 과거사 공개 조건 충족 → 허가된 청중에게만 공개 → 기억·관계 후속 반응 → 저장·복원을 검증한다. 공개 조건을 충족하지 못한 경로도 함께 확인한다.
3. **월별 사건을 확장한다.** 연결된 1~6개월을 검토하고 7~24개월 사건을 구간별로 데이터·판정·도입·대화·회귀 사례와 함께 추가한다. 13개월 논란은 후보별 적용 범위를 확정한 뒤 확장한다. 중도 종료와 마지막 결말까지 연결한다.
4. **긴 플레이를 평가하며 보완한다.** 개발 초기부터 표본을 쌓고, 수백 턴의 기억·인물별 반응·다인 대화·사실 정확도·지연·비용을 검증한다. 평가지표에 근거해 검색·요약·검증 방식을 조정한다.

첫 개발 단위의 완료 기준은 “대화가 나온다”가 아니라 **후보를 이해하고 선발한 선택이 팀 상태와 첫 활동에 반영되고, 저장 후 같은 상태로 이어지는 것**이다.

## 구현 방식을 아직 필수로 확정하지 않은 항목

임베딩·벡터 DB·LLM 요약은 기억과 검색을 개선할 수 있는 수단이다. 현재 어휘 검색이 어떤 회상에서 실패하는지 평가한 뒤 도입 여부를 정한다. 음성·스트리밍·이미지 유사도 검색·전용 게임 렌더러는 저장된 기획만으로 출시 필수 여부를 확정할 수 없다. 기능 유무 자체를 AI 완성 기준으로 삼지 않는다.

기기 간 이어하기·계정·저장 삭제/내보내기 등도 제품 완성에 별도 판단이 필요하지만, AI 입력 해석·대사 생성의 누락과는 담당이 다르다.
