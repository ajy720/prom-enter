# Part 4 프런트 데모 구현 전 비교·제안

> 이후 사용자가 13·17·21개월 서버 규칙 적용과 수익 밸런스 변경을 확정했다. 이 문서는 최초 제안 기록이다. 구현의 최종 규칙·서버 차이·수익표는 [Part 4 프런트 데모](../development/part4-frontend-demo.md)를 따른다.

2026-11-10. 사용자 요청과 현재 `backend/app/game/later_months.py`, `backend/app/content/months_07_24.json`을 비교했다. 이 문서는 구현 전 검토안이다. 아래의 **제안은 아직 확정하지 않았으며**, 현재 서버 규칙을 변경하지 않는다.

## 확정된 작업 범위

- 기존 Part 3와 같은 임시 대사·브라우저 저장 기반 프런트 데모다. 실제 AI·서버 판정으로 표시하지 않는다.
- Part 3의 12개월 완료 결과·신입·스텟을 이어받는다. 면담과 나레이션은 기존 공통 화면을 재사용하고 나레이션을 상황에 맞게 확장한다.
- 13개월은 신입만, 19개월은 국내·해외 모두 네 멤버 각각 최소 1회·최대 8회 면담한다. 사야는 해외 19개월에 일본어 부담이 없는 답변을 한다.
- 해외 20개월은 대응 선택 전 백하연과 3~7회 대화한다. 대화 내용으로 감정적 대응 여부를 판단한다.
- 영입 후 ‘대표님의 지시는 한 달 단위의 활동으로 진행됩니다.’ 안내 바로 다음에 국민 그룹·글로벌 스타·음악력 증명 목표 선택을 넣고 22개월까지 보존한다.
- 23개월은 인지도 80 이상·팬 20만 이상이면 올해의 노래, 그 외 인지도 60 이상·팬 10만 이상이면 본상, 나머지는 후보로 마친다.
- 24개월 자금 비교 기준은 최초 20억원이다. 분기 목표 실패 조건은 제외한다. 재계약 의향은 기록하지만 엔딩 등급은 누적 스텟으로 정한다.
- 해피는 그룹 활동 지속, 평범은 해산 후 개인 방송·예능 등의 활동, 잊혀진 그룹은 해산 후 일반인의 삶으로 연결한다. 재계약 의향에 맞게 도입 대사를 바꾼다.
- 13개월은 ‘띠링’ → 신입별 과거논란 글 사진 → 백하연 안내 → 여론 보기 버튼 → 같은 신입의 댓글 사진 → 신입 면담 순서다. 사용자가 제공한 이도·여울·사야의 여섯 PNG를 원본 그대로 사용한다.

## 미정 항목 제안표 — 확인 후 적용

팀=팀워크, 인=인지도, 팬=팬 수, 피=피로도. 명시하지 않은 스텟은 유지한다. 팬·자금은 최저 0, 일반 스텟은 0~100으로 제한하며 실제 적용된 변화량을 표시한다. 아래 값은 데모용 제안이며 실제 게임의 밸런스 확정값이 아니다.

| 항목 | 제안 |

## 결말 혼합 조건의 의미

예를 들어 자금 18억·팀워크 85·인지도 85·팬 45만이면 자금은 평범 조건, 나머지는 해피 조건이다. 네 조건을 모두 만족해야 한다면 원문의 세 결말 중 어느 것에도 속하지 않는다. 반대로 팀워크 30·인지도 85·팬 45만인 경우도 있다.

위 제안은 해피와 잊혀진 그룹의 모든 조건을 각각 확인하고, 그 사이 조합은 평범으로 분류해 빈 구간을 없앤다. ‘한 항목이라도 낮으면 잊혀진 그룹’으로 할지, ‘모든 항목이 낮아야 잊혀진 그룹’으로 할지에 따라 결과가 달라져 확인이 필요하다.

## 구현 전 확인할 핵심

1. 제안표의 수치·선택값, 특히 15개월 단체 예능 기준·21개월 수요 허용 범위·22개월 예산 비중을 사용할지.
2. 데모의 제한된 규칙 평가와 모호한 대화에 대한 지침 확인 선택을 사용할지. 무대응을 실패로 볼지.
3. 세 결말 혼합 조건을 위의 ‘해피 모두 충족 → 잊혀짐 모두 충족 → 나머지 평범’으로 분류할지.

22개월 잔여 자금 지출이 크므로, 제안대로라면 해피의 20억 초과 조건은 어려울 수 있다. 구현 시 12개월 실제 도달값으로 가능한 선택 경로를 계산해 보고하고, 도달 불가능하면 승인 없이 기준이나 보상을 변경하지 않는다.
