# 화면 방향과 디자인 토큰

최종 변경: 2026-11-11. 2026-11-06에 사용자가 승인한 후보 면담 화면을 기존 화면 전체의 기준으로 확장한다. 화이트·연핑크 팔레트와 실사 중심 방향은 유지하고, 초기의 큰 유리 패널·반복 설명 중심 배치는 아래 규칙으로 대체한다.

## 2026-11-10 화면 확인 후 확정

- 모든 나레이션은 사용자 제공 1개월차 화면처럼 원본 배경 위 월/장소·제목과 넓은 흰 대사창·다음 버튼으로 표시한다. 인물·스텟 사이드바·자금/기간 캡슐을 표시하지 않는다. 공통 `NarrationScene`을 사용한다.
- 면담 중에는 자금/기간 캡슐을 숨겨 채팅창과 겹치지 않게 한다. 운영 결정 화면의 표시는 유지한다.
- 4개월차 기자 대사는 나레이션과 같은 배경·제목·넓은 흰 대사창을 쓰고 화자 이름은 기자로 유지한다.
- 4개월차 백하연 안내 직전까지 사용자 제공 `무대_정방향.png`, 안내부터 기존 대표실 배경이다. 5개월차도 대표실 배경을 사용한다.

## 2026-11-11 사진 잘림·크기 보완 (#32)

- 대화용 기본·표정 사진 42장은 투명 여백을 제외한 인물 높이와 중앙을 기준으로 표시한다. 캐릭터·표정·대사 길이·입력/종료 상태가 바뀌어도 같은 화면 너비에서 같은 표시 높이를 유지한다. 백하연만 확대하던 이전 규칙은 대체한다.
- `PhotoSlot`의 `portraitFrames.ts` 경계값과 `portraits.css`를 공통으로 사용한다. 사진 원본·프로필·시작 단체사진은 변경하지 않는다.
- 화면에 들어가면 스크롤 없이 표시하고, 얼굴·어깨를 자르거나 인물을 줄여야 하는 경우 페이지 높이를 늘려 스크롤한다. 주 대화에 별도 내부 스크롤을 만들지 않는다.
- PC 인물 크기는 사용자가 2026-11-11 첨부한 후보 면담 화면을 기준으로 크게 유지한다. 왼쪽 정보와 인물이 겹치지 않게 별도 공간을 확보한다(2026-11-11 추가 수정). 같은 크기의 인물과 대화창이 나란히 들어가지 않으면 대화창을 아래로 배치해 페이지로 스크롤한다.
- PC에서 대화창이 인물 아래에 있으면 같은 인물 배율을 유지한 채 가슴 아래를 대화창 뒤로 가린다. 가로 배치의 하단은 실제 헤더·배너·패딩 높이에 맞춰 화면 끝에 정렬한다. 인물용 배치 스타일은 나레이션에 적용하지 않으며, 모바일의 기존 표시 범위는 유지한다.

## 2026-11-11 플레이 정보·UI 정리 (#23)

- 후보 선발 목록에서만 면담 전은 흰색, 완료는 연핑크 배경과 체크·완료 문구로 구분한다. 후보 선택 테두리는 별도로 유지하고 월별 면담 목록 색상은 바꾸지 않는다.
- 채팅 전송 후 입력이 다시 가능해지면 입력칸으로 포커스를 복원한다. 기다리는 동안 다른 조작 요소로 이동했거나 면담이 끝난 경우 포커스를 빼앗지 않는다.
- 데뷔조 프로필은 PC·노트북에서 전체 내용과 나가기 버튼을 스크롤 없이 배치한다. 모바일·낮은 화면은 스크롤을 허용하고 내용과 사진을 자르지 않는다.
- 오른쪽 대화창은 왼쪽으로 확장하되 왼쪽 정보·인물·대화 영역을 각각 확보한다. 정보와 인물이 겹치지 않게 하며 인물의 실제 불투명 폭과 간격, 표시 높이를 유지한다. 표정이 바뀌면 필요한 폭을 다시 계산하며, 나란히 들어가지 않으면 기존 아래 배치를 따른다.
- 현재 스텟은 운영 화면·팀 현황에서 확인하고 대화에 반복하지 않는다. 활동 비용과 남은 면담 횟수는 유지한다. 선택 전에는 행동의 의도를 설명하고 정확한 보상·성공 임계값·판정 공식은 표시하지 않는다. 결과 후 실제 변화량은 유지한다.
- 나레이션과 선발 후 백하연 안내의 신입은 선발된 캐릭터 이름과 자연스러운 조사로 표시한다. 백하연은 이름 뒤에 ‘씨’를 붙인다. 선발 전 도입·사용자 직접 입력·수상 소감 원문·직접 인용은 바꾸지 않는다. 백하연은 상황과 해야 할 일을 안내하며, 실제 월 진행에 맞춰 이야기한다.
- AI·데모 구분은 일반 대사창에서 빼고 기록 창의 ‘플레이 정보’에 표시한다. 독립 개발 데모의 명시적 안내는 유지한다.

### 같은 날 추가 확인

- 백하연 월별 안내의 제목은 인물 위에 띄우지 않고 독립된 상단 행으로 배치한다. PC 대화 영역은 최대 680px로 제한하며, 넓은 화면에서도 남는 공간을 모두 채우도록 늘리지 않는다. 제목·정보·인물과 겹치지 않는 것을 폭 확장보다 우선한다.

- 상단의 별도 시작 화면 버튼은 제거하고 `prom::enter.`를 누르면 시작 화면으로 돌아간다. 로고 링크의 기본·호버·포커스 밑줄은 제거하고 키보드 포커스 표시는 유지한다.
- 데뷔 전인 2·3개월차 인지도는 `-`로 표시한다. 저장된 수치와 판정에는 영향이 없다.
- 5개월차 예산은 입력 중 빈칸을 유지하며 앞의 불필요한 0을 제거한다. 확정 시 원 단위 정수로 보내고 총예산 검증을 유지한다.
- 8개월차는 백하연 안내와 함께 ‘컨디션 관리 선택’ 버튼을 표시한다. 누르면 중간 선택 화면 없이 바로 관리 팝업을 열며 확정 전에는 비용·효과를 적용하지 않는다.

## 2026-11-11 Part 3 결산 배경 (#46)

- 12개월차 수상 소감은 기존 사용자 제공 무대 사진을 사용한다. 트로피 진열 나레이션부터 백하연의 반기 결산과 ‘우리의 첫해를 마치며’ 완료 화면은 대표실 사진을 사용한다. 수상·미수상 모두 같은 장소 구분을 적용한다.
- 사진 원본과 인물 크기·단계·판정·보상은 유지한다. 후보 목록·최종 선발 목록·영입 확정의 흰색 구성은 변경하지 않는다.

## 공통 시각 규칙

- 배경·인물·대사가 중심이다. 한 장면의 주요 대사·입력·진행은 하나의 흰색 영역에 묶는다. 이름표에 별도의 핑크색 박스를 덧대지 않는다.
- 흰색을 기본으로 하고 연핑크는 주요 행동·선택 상태에만 사용한다. 기존 팔레트 `#D8E2DC`, `#FFE5D9`, `#FFCAD4`, `#F4ACB7`, `#9D8189`를 유지한다. 피부·의상에는 색 필터를 씌우지 않는다.
- 보조 정보는 작은 글자·구분선·여백으로 정리한다. 같은 설명이나 감성 문구를 여러 패널에 반복하지 않는다.
- 패널·대사창의 모서리는 10px, 간격은 4·8·12·16·24·32·48px를 기본으로 한다. 기존 한국어 글꼴과 16~19px 대사를 유지한다. 큰 그림자·광택·상시 흐림 효과·핑크색 상단 장식선은 사용하지 않는다.
- 보라·파랑 그라데이션, 네온 빛 번짐, 그라데이션 글자를 사용하지 않는다. 아이콘·제목·설명 카드 3개를 기계적으로 반복하지 않는다.
- 버튼은 실제 행동에만 사용한다. 미구현 기능은 상태 텍스트로 표시한다. 처리 중·조건 미충족·이미 사용한 실제 행동의 비활성화는 유지한다.
- 사진이 잘린 경계가 화면에서 드러나지 않게 한다. 원본이나 표시 영역의 하단 경계는 대사창 뒤에 가리거나 화면 끝에 맞춘다. 사진 아래에 여백이 남아 인물이 잘린 채 떠 있는 것처럼 보이지 않게 한다.
- 이어지는 장면에서 같은 인물의 얼굴·머리 크기를 일정하게 유지한다. 이름 입력·면담 종료처럼 화면 구성이 바뀌어도 인물의 표시 배율이 갑자기 달라지지 않게 한다.
- 얼굴과 머리, 어깨까지 가리지 않는 범위에서 몸통을 대사창 뒤에 배치할 수 있다.

## 화면별 구성

| 화면 | 적용 기준 |
|---|---|
| 시작 | PC는 왼쪽 단체사진·오른쪽 제목과 버튼, 모바일은 상단 제목·중앙 사진·하단 버튼. 사용자 제공 사진 세 장을 동일 크기·기준점으로 절대 배치하고 왼쪽→오른쪽 소프트 마스크로 2초 ease-in-out 와이프·크로스페이드 순환 전환. 시작/이어하기·저장/복원 유지 |
| 도입·비서 안내 | 장소는 배경 위 작은 흰색 글자, 대사는 흰색 영역에 표시. 단계·이전/다음·호칭 입력·프로필 열기 유지 |
| 소개·후보 목록·최종 선발 | 실제 사진과 이름·역할 중심. 프로필 사진은 잘라 채우기보다 원본 전체가 보이도록 contain으로 표시한다. 선택은 사진·이름 영역을 둘러싼 테두리와 aria-pressed로 구분. 키워드는 텍스트, 상세 설명은 구분선으로 분리 |
| 후보 면담 | 자금·계약 기간 표시 없음. 기록·직접 종료·8회 마지막 답변 후 다음·목록 복귀 유지 |
| 영입 확정·팀 안내 | 실제 선발 신입과 기존 세 명의 사진 유지. 팀 정보는 간결한 텍스트와 수치로 표시. PC 안내의 백하연은 좌우 정보 폭을 대칭으로 맞춘 중앙 열에 배치 |
| 첫 달 활동·완료 | 운영 메뉴·인물·대사 구분. 서버 자금·기간·상태 표시. 실제 선택·확정과 미구현 이후 단계의 상태 구분 |
| 선택·기록 팝업 | 흰색 바탕과 얇은 구분선, 닫기 버튼. 훈련·규칙은 행 목록으로 표시하고 선택 상태 구분 |

## 버튼의 역할과 형태

| 역할 | 형태 |
|---|---|
| 게임 시작 | 큰 캡슐형 CTA. 시작 화면에서만 사용 |
| 영입·계획 확정·다음 진행 | 채운 버튼, 모서리 6px. 주요 행동에만 강조색 사용 |
| 이전·시작 화면·기록 보기 등 보조 이동 | 테두리 없는 텍스트 버튼. hover·키보드 포커스 제공 |
| 프로필 열기·활동 메뉴·오류 재시도 | 얇은 외곽선 버튼, 모서리 4px |
| 팝업 닫기 | 원형 X 아이콘 버튼. 접근성 이름과 44px 조작 영역 유지 |
| 대화 상대 | 대사창 위의 테두리 선택 버튼. 선택 상태와 면담 현황을 구분 |
| 기록 종류·기록 상대 | 캡슐 그룹 안에서 선택하는 분할 버튼 |
| 훈련·합숙 규칙 운영 메뉴 | 사각형 상자 없이 텍스트·화살표·하단 구분선으로 된 행 |
| 채팅 전송 | 기존 원형 위쪽 화살표 버튼 유지 |

레퍼런스의 색상을 복사하거나 버튼 모양을 무작위로 섞지 않는다. 같은 역할에는 같은 형태를 적용하고 실제 동작·잠금·선택 상태를 유지한다.

## 채팅과 질문 예시

- 공통 [ChatComposer.tsx](../../frontend/src/ChatComposer.tsx)의 캡슐형 입력창·연핑크 원형 위쪽 화살표 버튼을 사용한다.
- 입력칸은 44px 높이로 고정한다. 긴 문장·붙여넣기·Shift+Enter 줄바꿈은 내부 스크롤로 확인한다. 모바일 글자는 16px, 전송 버튼은 최소 44px이다.
- 질문 예시는 펼쳐 선택하면 초안만 채우고 입력칸에 포커스를 옮긴다. 사용자가 수정·전송할 수 있어야 하며 선택만으로 API 호출·횟수 증가·답변 생성은 하지 않는다.
- Enter는 전송, Shift+Enter는 줄바꿈이다. IME 조합 중 전송을 막고 빈 입력·처리 중·미해결 요청·완료 상태는 기존 잠금을 따른다. 서버 판정과 데모/실제 모델 구분을 유지한다.

## 자금·계약 기간

- 운영 안내·영입 후 팀 안내·월별 활동 등 필요한 화면은 [ResourceStatus.tsx](../../frontend/src/ResourceStatus.tsx)를 사용한다. 후보 면담에는 표시하지 않는다.
- 하나의 긴 캡슐 안에 지갑 아이콘·금액과 달력 아이콘·전체 계약 기간을 가로로 배치한다. 지정 팔레트의 연핑크 `#FFCAD4`를 불투명도 80%의 반투명 배경으로 사용하고 모브 `#9D8189` 테두리를 둔다. 숫자·아이콘은 투명하게 만들지 않고 가독성을 위해 기존 보조 글자색 `--ink`를 사용한다. 네온·그라데이션·상단 장식선은 없다. 표시 항목을 버튼처럼 만들거나 기능 없는 펼침 아이콘을 추가하지 않는다.
- 금액은 `20.00억원`, 전체 계약 기간은 `24개월` 형태로 표시한다. 숫자 22px·굵기 600(모바일 20px), 아이콘 22px(모바일 20px), 최대 너비 340px이다. 항목명과 현재 월은 툴팁·스크린 리더로 제공하고 운영 안내 팝업에서는 현재 월도 본문에 표시한다.
- 잔액 경고는 강조 테두리와 숫자 밑줄로 구분한다. 실제 활동은 서버 잔액·현재 월을 전달한다. `계약 기간 24개월`은 전체 기간이며 남은 기간과 구분한다.

## 이미지·코드·검증

- 사용자가 직접 제공한 원본·배경 제거본을 사용한다(2026-11-09 변경). 공유 폴더는 더 이상 조회·사용하지 않는다. [캐릭터 안내](../../frontend/public/images/characters/README.md)와 [장면 안내](../../frontend/public/images/scenes/README.md)의 매핑을 따른다.
- 원본 비율·색상을 유지하고 얼굴·머리·어깨를 가리지 않는다. 사진별 구도는 표시 위치로 조정한다. 없는 사진·표정을 생성하거나 시작 단체사진을 실제 선발 결과로 재사용하지 않는다.
- 공통 값은 [tokens.css](../../frontend/src/tokens.css), 공통 규칙은 [design-system.css](../../frontend/src/design-system.css), 기존 장면 배치는 [style.css](../../frontend/src/style.css)에 둔다.
- PC는 인물과 읽는 영역을 분리하고 좁은 화면은 정보·인물·대화 순서로 배치한다. 가로 넘침·사진의 잘린 경계 노출·얼굴/머리/어깨 가림·장면 전환 전후 인물 크기·긴 대사·팝업·키보드 포커스를 확인한다. 빌드·관련 상태 테스트와 데모 연결을 확인하고 실제 기기·IME·유료 모델은 수행한 범위만 보고한다.
- 2026-11-09 승인한 1·2개월차 배경은 사용자 제공 `연습실_정방향1.png`다. 인물이 있는 장면은 배경에만 검정 50% 레이어(`--scene-dim`)를 얹고, 인물에는 기존 윤곽 그림자(`--portrait-shadow`)를 적용한다. 인물 없는 나레이션은 검정 레이어 없이 원본 배경을 표시한다. 인물 원본 색과 흰색 대화 영역을 유지하고 배경 위 제목·상태 정보는 흰색으로 표시한다.
- 같은 사진 규칙을 1개월차 전 도입·후보 소개·후보 면담·영입 후 안내에도 적용한다. 첫 나레이션은 원본 배경, 대화 장면은 배경 검정 50%·인물 윤곽 그림자를 사용한다. 대화용 정사각 PNG의 투명 여백은 CSS로 조정하고 하단 경계를 대사창 뒤 또는 화면 끝에 맞춘다. 시작 단체사진과 프로필·영입 확정용 배경 포함 사진은 원본 색과 기존 용도를 유지하며, 프로필 목록은 contain으로 전체를 표시한다.
- 백하연의 대화용 사진은 대화창이 바로 아래에 있는 세로 배치에서만 얼굴·어깨를 유지하면서 가슴 아래까지 확대한다. 인물 왼쪽·대화창 오른쪽인 가로 배치는 기존 골반까지 보이는 구도를 유지한다. PC·모바일의 실제 배치 전환 시점에 맞춰 전환하며 다른 인물과 프로필 원본은 확대하지 않는다.

## 시작 화면 배치 · 2026-11-06 추가 승인

- 화이트·연핑크 팔레트와 원본 사진을 유지한다. PC·노트북은 바깥 여백과 최대 너비 제한 없이 화면 전체를 사용하고, 왼쪽 사진은 화면 높이를 채운다. 동일한 cover/상단 중앙 기준점으로 세 사진을 표시하며 일부 가장자리만 잘릴 수 있다. PC 제목·소개·시작/이어하기는 오른쪽에서 최대 400px 폭의 한 묶음으로 세로 중앙에 배치하고 왼쪽 정렬과 버튼 폭을 통일한다. 제목은 한 줄 세리프 워드마크로 표시한다. 제목과 버튼에 별도의 카드·설명 상자를 추가하지 않는다.
- 첫 사진을 먼저 표시하고 나머지 사진이 준비되면 4.5초마다 왼쪽에서 오른쪽으로 다음 의상을 보여준다. 세 번째 사진에 도달하면 고정한다. 전환 시간은 2초, easing은 ease-in-out이다. 인물의 위치·크기와 사진 기준점을 고정하고 부드러운 마스크 경계만 이동해 의상만 바뀌는 느낌을 유지한다. 사진 자체를 좌우로 이동하거나 확대·축소하는 애니메이션은 사용하지 않는다.
- 동작 줄이기 설정에서는 첫 사진을 고정한다. 좁거나 낮은 화면은 콘텐츠를 자르지 않고 세로 스크롤을 허용한다.

## 플레이 화면 스크롤 · 2026-11-06 수정

- PC(CSS 너비 1001px 이상)는 일반 안내·소개·선발 화면을 화면 높이에 맞춘다. 다만 이름 입력·대화 입력 화면은 인물과 입력 영역을 유지하는 기존 페이지 스크롤 배치를 사용한다.
- 실제 콘텐츠를 측정해 화면 안에 들어가지 않거나 내부 스크롤이 필요해지는 장면만 페이지 스크롤 배치로 전환한다. 화면에 맞추려고 내용을 자르거나 인물을 과도하게 축소하지 않는다. 주 플레이 영역의 긴 대사·설명·완료 요약은 페이지와 함께 읽도록 하며 별도 내부 스크롤에 넣지 않는다. 내용·화면 크기 변경 시 다시 판정한다. 모바일은 기존 세로 배치에서 브라우저 도구 모음에 따라 장면 높이가 출렁이지 않도록 작은 뷰포트 높이(100svh)를 최소 높이로 사용한다. 시작·안내·면담은 16px의 공통 여백을 적용한다.
- 기록·팝업의 기존 스크롤은 유지한다. 데뷔조 프로필 열기 버튼은 내용 너비로 표시하고 제목은 '무대를 기다려온 세 사람'으로 쓴다.
