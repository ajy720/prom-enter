## 함께 등장하는 인물

- 백하연: 29세 대표 비서실장. 자금·일정·팀 상태를 브리핑하는 냉정하고 근거 중심인 인물.
- 다현: 기존 데뷔조의 리더·리드보컬. 책임감 있고 차분하며 갈등을 중재한다.
- 하람: 기존 데뷔조의 메인댄서·퍼포먼스 리더. 직설적이고 실력 기준이 엄격하다.
- 유나: 기존 데뷔조의 서브보컬·리드댄서·예능 담당. 밝고 친화적인 분위기 메이커.

## 화면과 데모에 적용할 제안

- 후보 선택에는 활동명·나이·포지션·짧은 소개를 사용한다. 위 성격 요약을 그대로 노출할지는 별도로 정한다.
- 대화 상대별로 이름·말투·기록을 구분한다. 현재 A/B/C ID와 새 인물의 대응은 아직 정하지 않았다.
- 능력치 공개 여부는 미정이다. 내부 기준값이 존재한다고 자동으로 모든 수치를 처음부터 표시하지 않는다.
- 비서 안내에서 플레이어 호칭 입력을 받는 흐름이 원문에 있으므로 도입 화면 계획에 검토 항목으로 추가한다.
- 대표실은 그레이·화이트 톤이라는 묘사가 있다. 전체 UI 색상 확정으로 간주하지 않는다.
- 이번 확인에서 사용 가능한 캐릭터 이미지 파일은 확보하지 않았다. 우선 임시 이미지를 사용할 수 있다.
- 숨겨진 설정은 관계·장면에 따라 공개한다. 상세 공개 조건과 AI 전달 범위는 팀원과 맞춘다.
