## 화면과 데모에 적용할 제안

### 2026-11-03 화면 콘텐츠 갱신

- 상세 시트의 이름·본명·나이·연습 기간·포지션·초기 능력치를 반영했다. 노션 도입부에는 이전 이름이 남아 있으므로 새 상세 시트의 명단을 사용한다. 이도의 본명 `이이도`도 원문 표기다.
- 여울의 구미 출신·빠른 성장·스타성, 이도의 보컬 재능·무대 긴장, 사야의 일본 출신·유창한 한국어·랩/작사 강점을 기존 소개·키워드·데모 대사에 반영했다.
- 도입 안내와 영입 결과에도 리안·도하·세인을 표시한다. 화면 배치·CSS·색상은 수정하지 않았다. 사진은 기존 자리 표시를 유지한다.
- 저장 및 팀원의 AI 자료와 호환되도록 내부 ID `dahyun/haram/yuna/seoyeon/hyerin/jiwoo`를 유지한다. 각각 리안/도하/세인/여울/이도/사야에 대응한다. 후보 ID는 모델 ID가 아니다.
- 과거 면담의 본문은 다시 쓰지 않는다. 이어하기에서는 현재 이름으로 발화자를 표시하되 당시 대사에 이전 이름이 남을 수 있다. 새 게임은 모두 새 소개와 대사를 사용한다.
- 특성은 소개용 콘텐츠다. 훈련 효율·피로·팀워크 등 서버 게임 규칙은 이번 변경에 포함하지 않았다. 최신 main의 AI 기능도 이번 콘텐츠 수정에 병합하지 않았다.
- 기존 미리보기 이미지는 갱신 전 화면 기록이다. 최신 확인 화면은 [캐릭터 콘텐츠](design/preview-current-characters.jpg)를 참고한다.

- 후보 선택에는 활동명·나이·포지션·짧은 소개를 사용한다. 위 성격 요약을 그대로 노출할지는 별도로 정한다.
- 대화 상대별로 이름·말투·기록을 구분한다. 현재 A/B/C ID와 새 인물의 대응은 아직 정하지 않았다.
- 능력치 공개 여부는 미정이다. 내부 기준값이 존재한다고 자동으로 모든 수치를 처음부터 표시하지 않는다.
- 비서 안내에서 플레이어 호칭 입력을 받는 흐름이 원문에 있으므로 도입 화면 계획에 검토 항목으로 추가한다.
- 대표실은 그레이·화이트 톤이라는 묘사가 있다. 전체 UI 색상 확정으로 간주하지 않는다.
- 이번 확인에서 사용 가능한 캐릭터 이미지 파일은 확보하지 않았다. 우선 임시 이미지를 사용할 수 있다.
- 숨겨진 설정은 관계·장면에 따라 공개한다. 상세 공개 조건과 AI 전달 범위는 팀원과 맞춘다.
