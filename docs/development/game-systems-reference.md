# 운영 시스템 참고와 대화 탐색

확인일: 2026-11-03.

앞으로 운영 시스템을 수정할 때 [AI 캐릭터 챗. 팀명: ent.](https://app.notion.com/p/AI-ent-3f95e6f37af280b592a5da1658601c4f)의 '챗봇 시나리오 정리 → 운영 시스템'을 함께 참고한다. 캐릭터별 상세 설정은 [캐릭터 자료](character-reference.md), 월별 사건은 [Figma 원문 정리](../../storyline/README.md)와 구분한다. 서로 다른 자료가 충돌하면 사용자 정정을 우선하고 나머지는 미정으로 기록한다.

## 노션에서 확인한 기준

| 구분 | 항목과 범위 | 표시/해석 |
|---|---|---|
| 팀 능력치 | 대중적 인지도, 팬덤 규모, 팀워크, 스트레스 및 피로도 · 각 0~100 | 앞의 세 지수는 높게, 스트레스/피로도는 낮게 관리 |
| 회사 자금 | 트레이닝·제작·홍보·고정비·수익과 연계 | 팀 능력치와 별도 자원. 예상 초기 20억이며 밸런스 테스트로 확정 예정 |
| 개인 능력치 | DANCE, VOCAL, VISUAL, VARIETY, PERSONALITY · 각 1~10 | PERSONALITY는 인간의 도덕적 우열이 아닌 협업·대인관계 성향 |
| 랩 | 연습생별 특성 | 보컬 점수와 자동 연동하지 않음 |

새 노션의 초기 기획에는 '7명 중 4명 선발·6개월 안 데뷔·3년 계약'도 적혀 있다. 이는 현재 사용자와 정한 '기존 세 명 + 신입 한 명·프로뮤의 2년 계약·Part 1에서 쇼케이스까지 3개월 안내'와 다르므로 이번 요청으로 선발·기간·월별 흐름을 덮어쓰지 않는다.

## 현재 화면 적용

- 자금 표시의 최신 근거는 [캐릭터챗 enter. 수정본의 운영 시스템](https://app.notion.com/p/enter-3be5e6f37af280188111e15a960357a5#4095e6f37af280cfb39ec9a9a92df807)이다. 20억 원 초기 자금 권장, 3억 원 이하 경고, 억 원 단위 소수점 둘째 자리, 골드/경고 레드 표기를 확인했다. 월 고정비 약 4,000만 원은 기획 가정이며 이번 프런트에서 실제 차감하지 않는다.
- `CompanyFunds.tsx`는 20.00억 원을 데모 초기값으로 표시한다. 프롤로그의 첫 자금 안내에서 소개하고, 후속 사용자 요청에 따라 영입 후 비서 안내와 첫 달 왼쪽 상태 패널에서 팀 능력치 위에 계속 표시한다. 첫 달 면담 중에도 유지하며 훈련·계획 확인 팝업 안의 중복 표시는 제거했다. 실제 자금 계산·파산 판정은 서버 소유로 유지하고 아직 구현하지 않았다.

- 합숙 전 비서 안내와 첫 달 패널에서 `TeamStatus.tsx`의 네 가지 팀 능력치를 공통 표시한다.
- 기존 화면의 팀워크 40·피로도 20은 [Figma S014](../../storyline/sources/figma-text.md#s014)의 '초기 팀 40/피 20'을 가져온 값이다. 새 노션에서 모든 초기값을 확정한 것으로 설명하지 않는다.
- 인지도·팬덤은 새 노션에 초기 수치가 없어 `— / 100`, '초기값 미정'으로 표시한다. 0이나 캐릭터 평균으로 만들지 않는다.
- 팬덤 지수와 실제 팬 수는 다른 형식이다. 기존 축약 데모의 서버 `fans`는 팬 수이므로 그대로 유지하고 새 0~100 지수로 재해석하지 않는다. 신뢰도 역시 별도 관계 수치이며 네 가지 팀 능력치에 섞지 않는다.
- 실제 능력치 변화·성공/실패·비용은 서버 계산이 필요하다. 이번에는 표시를 수정했으며 API·AI 계약·게임 규칙은 변경하지 않았다. 개인별 PERSONALITY의 초기값도 임의 생성하지 않았다.

## 대화의 이전 버튼

- 프롤로그는 기존 이전/다음으로 장면을 다시 읽는다.
- 기존 축약 데모는 사용자 질문과 응답을 포함해 이전/다음으로 읽고 '최근 대화로' 복귀한다. 발화자와 이미지도 보고 있는 대사에 맞춘다.
- 첫 달의 신입·기존 멤버 면담도 이전/다음 탐색을 제거했다. '대화 기록 보기'로 현재 멤버의 기록을 열고, 창 안의 이름 버튼으로 네 멤버의 기록을 각각 확인한다. 대화 전에는 빈 기록 안내를 표시하며 계획 확정 후에도 멤버별 기록을 열 수 있다. 합숙 도입 장면의 이전/다음은 유지한다.
- 연습생 면담은 사용자 후속 요청에 따라 이전/다음 탐색을 제거했다. 면담 화면과 연습생 선택 화면의 '면담 내용 다시보기'에서 해당 연습생의 전체 기록을 읽는다. 완료한 면담은 선택 화면에서 기록 창으로 바로 열리고, 진행 중인 면담은 이어하기와 다시보기를 따로 제공한다.
- 첫 합숙 도입도 지난 장면을 다시 읽을 수 있다. 첫 장면의 이전은 합숙 전 비서 안내로 돌아간다. 비서 안내에서는 이전으로 사진 확정 단계까지 돌아갈 수 있다.
- 이것은 대사 열람 기능이며 영입·계획·대화 횟수·능력치를 되돌리거나 AI를 재호출하지 않는다. 과거 대사를 읽는 동안 입력·추천 질문·새 결정은 비활성화한다.
- 비서의 합숙 전 안내에서는 면담 기록과 영입 확정 사진 보기 버튼을 제거했다. 사진 창은 영입 확정 단계에 유지하며, 이전으로 돌아가 다시 볼 수 있다.
- 대화 탐색 위치는 화면 안의 임시 상태다. 새로고침하면 저장된 실제 진행과 최근 대화로 복원한다.

## 확인

- 프런트 빌드와 상태 관리 테스트 6개 통과, `git diff --check` 이상 없음.
- 별도 5175 포트에서 비서 안내의 이전 이동과 버튼 제거, 완료한 면담의 질문/답변 다시 읽기, 첫 합숙 도입과 대화 탐색, 과거 대화 열람 중 입력·새 결정 잠금을 확인했다.
- 390px 모바일에서 가로 넘침이 없음을 확인했다. [수정 화면](../design/preview-team-status-navigation.jpg).
- 기존 서버 축약 데모는 빌드로 확인했으며 이번 작업에서 실제 서버를 연결해 실행하지 않았다. 실제 AI 호출도 하지 않았다.
- 면담 탐색 변경 후 프런트 빌드와 diff 검사를 통과했고, 완료한 사야·여울을 각각 선택해 서로 다른 전체 기록 창이 열리는 것을 확인했다. [면담 다시보기 화면](../design/preview-interview-records.jpg).
- 첫 달 면담 변경 후 빌드와 상태 테스트 6개를 통과했다. 5175 포트에서 사야 기록 열기·리안의 빈 기록·리안에게 질문 후 기록 열기·면담 화면의 이전/다음 제거를 확인했다. [멤버별 첫 달 기록](../design/preview-month-member-records.jpg).
- 자금 표시 추가 후 빌드·상태 테스트 6개·diff 검사를 통과했다. 첫 달 면담의 자금 숨김과 훈련 선택 창의 20.00억 원 표시를 브라우저에서 확인했다. [자금 표시](../design/preview-company-funds.jpg). 3억 이하 경고 분기와 첫 자금 안내의 실제 화면은 이번 확인에서 실행하지 않았다.

- 자금 상시 표시 변경 후 빌드·diff 검사를 통과했고, 첫 달 왼쪽 패널의 자금과 팀 능력치 배치 및 대화창과 겹치지 않음을 확인했다. [왼쪽 자금 패널](../design/preview-company-funds-panel.jpg).

## 자금·시간 안내 후속 수정

- 자금 부족 안내 → 다음 → 현재 자금·시간 팝업 → 확인 → 신입 한 명 선발 안내 순서로 분리했다. 기존 장면 번호는 유지해 이전 저장의 장면을 밀지 않는다.
- `resourcesIntroduced`를 저장하며 과거 저장이 해당 안내를 이미 지난 경우에도 표시가 이어진다. 확인 후 새로고침하면 두 번째 대사에서 계속한다.
- `ResourceStatus.tsx`는 자금 20.00억 원, 프로뮤 계약 종료까지 24개월, 쇼케이스까지 3개월을 표시한다. 안내 후 일반 대화·신입 소개·일대일 면담·영입 후 안내·첫 달 면담의 왼쪽 상태 영역에 유지한다. 선택 목록·사진 확정 창·시작 화면에는 표시하지 않는다.
- 아직 첫 달 계획 데모이므로 실제 월 경과나 비용 차감을 계산하지 않는다. 계획 확정 자체를 한 달 경과로 처리하지 않는다.
- 빌드와 상태 테스트 6개 통과. 5175에서 첫 안내 전 숨김, 대사 분리와 팝업, 확인 후 왼쪽 표시, 새로고침 복원, 모바일 390px에서 가로 넘침 없음을 확인했다.
- 미리보기: [자금·시간 안내](../design/preview-resource-notice.jpg), [안내 이후 상태 표시](../design/preview-resource-status.jpg).

- 최신 배치 수정: 대화 중 자금·시간은 오른쪽 상단의 작은 두 칸 패널로 표시하며, 왼쪽 장소 표시는 복원했다. 첫 안내 팝업은 기존 크기를 유지한다. 면담·영입 후 안내·첫 달에서도 동일한 작은 패널을 사용한다. 빌드·diff 검사와 프롤로그 실제 화면을 확인했다. [최신 상태 표시](../design/preview-resource-compact.jpg). 이전 미리보기의 왼쪽 큰 패널은 변경 전 기록이다.

- 반응형 수정: 1000px 이하에서는 자금·시간에 별도 상단 행을 확보하고 글자·여백을 줄인다. 소개 화면의 패널도 사진 영역 밖으로 분리했다. 프롤로그·신입 소개·면담을 각각 900/700/390/320px에서 확인해 본문 겹침과 가로 넘침이 없었다. [작은 화면](../design/preview-resource-responsive.jpg).

## 최종 표시 기준

- 대화 중 오른쪽 상단은 `자금: 20.00억원`, `기간: 24개월` 두 줄이다. 첫 자금 안내 팝업에서만 상세한 계약 기간과 쇼케이스 일정을 함께 설명한다.
- 사용자 후속 요청에 따라 연습생 소개 페이지에서는 자금·기간을 숨긴다. 일반 안내·면담·영입 후 안내·첫 달 화면에는 유지한다.
- 수치는 데모 초기값이며 실제 월 경과·지출·수익·파산 계산을 구현하지 않았다. 이전 미리보기는 각 수정 당시의 기록이다.
