# 인물 설정

현재 사용하는 자료는 이 폴더의 `00.`~`06.` Markdown 7개다. [2026-11-02 수정본](https://app.notion.com/p/enter-3be5e6f37af280188111e15a960357a5)의 각 상세 시트와 맨 아래 **한 눈에 보는 캐릭터 특성 요약**을 반영했다.

- [수정본 텍스트 보존본](sources/notion-2026-11-02.md): 상세 시트 7개와 하단 요약의 문구를 보존했다. Notion의 서식 강조는 포함하지 않는다.
- [이전 원본](archive/initial/): 기존 Markdown 8개를 내용 변경 없이 보존했다. 컴파일에는 사용하지 않는다.
- `knowledge-policy.json`: 표면 성향의 초기 인지자와 본인이 면담에서 말할 수 있는 원문 과거 경험의 문단을 지정한다. 전체 과거사·핵심 비밀은 별도 공개 조건을 유지한다.

| 현재 이름 | 나이 | 새 영문 입력 별칭 | 유지하는 내부 ID |

| 리안 | 21세 | `rian` | `dahyun` |
| 도하 | 20세 | `doha` | `haram` |

내부 ID와 지식 자료 ID는 기존 저장·개별 인지·공개 허가를 보존하기 위해 유지한다. 콘솔에서는 현재 이름과 영문 별칭을 모두 사용할 수 있다. 선택 슬롯은 `a=이도`, `b=여울`, `c=사야`다. 이미 저장한 과거 발언의 문구는 다시 쓰지 않는다.

## 원문이 서로 다른 부분

외형의 충돌은 사용자가 지목한 **맨 아래 요약을 우선**하는 기준으로 반영했다. 원문 보존본에는 양쪽 문구가 모두 남아 있다.

| 인물 | 상세 시트 | 하단 요약을 반영한 현재 자료 |
|---|---|---|
| 리안 | 짙은 갈색 긴 머리 | 요약의 고동색과 같은 계열로 유지 |
| 도하 | 앞머리가 없는 흑발 단발 | 앞머리 있는 흑발 단발 |
| 세인 | 흑갈색 긴 머리 | 검정색 긴 S컬 웨이브·고양이상 |
| 여울 | 긴 머리, 묶거나 풀어 다님 | 검정 긴 생머리·왼쪽 보조개·얇은 허리 |
| 이도 | 연갈색 생머리 | 타고난 연갈색 머리·동공과 복숭아 이미지 추가 |
| 사야 | 169cm | 167cm·짧은 중안부 |

성격·말투·국적·출신·나이·연습생 기간·초기 능력치는 상세 시트를 따른다. 하단 요약의 역할·강점 문구도 기본 프로필에 `하단 요약`으로 함께 반영했다. 특히 여울은 구미 출신으로 표준어와 자연스러운 사투리를 섞으며, 사야는 일본 출신이지만 한국어를 능숙하게 구사한다. 이도의 본명 `이이도`는 상세 시트 표기를 그대로 보존했다.

상세 시트의 과거 입사 나이와 현재 나이·연습 기간, 페이지 도입부의 이전 후보 이름, 계약/데뷔 기간의 불일치는 기획 확인이 필요하다. 이번에는 인물 페르소나만 갱신했으며 기존 시나리오·실제 게임 수치·엔딩을 새로 확정하지 않았다.

수정 후 저장소 루트에서 실행한다.

```sh
backend/.venv/bin/python scripts/compile_characters.py
```

컴파일 결과는 `backend/app/content/characters.json`이다. 실행 중인 서버와 페르소나 콘솔은 재시작해야 새 자료를 읽는다.
