출처는 [프로듀서 공유 폴더](https://cloud.ajy720.me/s/AETsqjRA7QQp9xF)다.
2026-11-04에 확인한 `단체사진/단체사진.png`를 `cover.png`로 복사해 시작 화면에 연결했다.
2026-11-05에 공유 폴더의 최신 목록을 다시 확인하고, 시작 화면용 `단체사진/시작화면.png`를 `title.png`로 추가해 시작 화면 연결을 교체했다. 기존 `cover.png`는 보존한다.
2026-11-06 시작 화면 개편에서는 사용자가 직접 첨부한 `단체사진.png`, `단체사진3.png`, `단체사진4.png`를 우선 적용했다. 각각 `title-white.png`, `title-uniform.png`, `title-black.png`에 원본 바이트 그대로 보존했다(모두 1536×1024). 이번 직접 지정 파일은 공유 폴더에서 다시 내려받은 파일이 아니다. 출처·해상도·SHA-256은 manifest에 별도로 기록했다.
PC는 왼쪽 사진·오른쪽 제목/버튼, 모바일은 제목·사진·버튼 순서다. PC·노트북은 외곽 여백 없이 사진이 화면 높이를 채우도록 cover/상단 중앙 정렬하며, 모바일은 전체 원본을 contain으로 표시한다. 세 사진은 같은 컨테이너에 absolute로 겹치며 동일한 object-fit/object-position을 사용한다. 전환은 이전 사진을 아래에 유지하고 다음 사진의 소프트 마스크만 왼쪽에서 오른쪽으로 2초 ease-in-out으로 펼친다. 경계의 반투명 구간에서 두 의상을 크로스페이드하며, 이동·확대 애니메이션을 사용하지 않는다. 원본 구도에 포함된 미세한 차이는 별도의 이미지 변형으로 보정하지 않는다.
사진을 교체할 때는 사용자 지정 원본 또는 공유 폴더 최신 파일을 확인한 뒤 세 사진의 크기와 인물 기준점이 같은지 확인하고 manifest의 출처와 해시를 갱신한다. 기존 `cover.png`, `title.png`는 보존한다.

단체사진은 시작 화면의 소개용이며, 실제 선발 결과의 네 명을 나타내는 사진으로 사용하지 않는다.
