# 캐릭터 이미지

이미지 기준은 [프로듀서 공유 폴더](https://cloud.ajy720.me/s/AETsqjRA7QQp9xF)다. 앞으로 이미지 작업을 시작할 때 이 폴더의 최신 파일을 확인한다. 2026-11-04에 아래 28장을 내려받았으며, 파일 내용은 재압축·크기 변경·색 보정 없이 그대로 보존했다.

2026-11-05에 공유 폴더를 다시 조회하고 배경 제거본·프로필1 각 7장의 SHA-256이 로컬 manifest와 일치함을 확인했다. 백하연 안내·후보 소개·후보 면담·영입 결과·1개월차 대화 인물에는 `half-body-transparent.png`를 사용한다. 사진 경로는 `introContent.ts`의 `characterPortraits`에서 기존 인물 ID에 대응시킨다. 첫 내레이션에는 배경만 표시한다.

기존 멤버 프로필과 후보 면담·최종 선발 목록에는 `characterProfiles`에 기록한 `profile.png`(프로듀서의 프로필1)를 사용한다. 최종 영입 확정 창만 예외로, 선발 신입은 배경이 있는 `half-body.png` 원본, 기존 멤버 3명은 `profile-2.png`를 사용하며 `RecruitmentResult.tsx`의 `recruitmentPhotos`에서 대응시킨다. 서버 화면과 브라우저 데모 모두 같은 사진 대응을 사용한다. 후보 면담의 백하연 사진은 기존 화자 판정에 따라 8회 종료 안내에서만 표시한다. 1개월차는 현재 대사의 화자를 기준으로 신입·리안·도하·세인·백하연 사진을 표시하며, 훈련·규칙 선택만으로 대화 상대나 사진을 바꾸지 않는다. 사진 변경으로 면담 횟수·기록·종료·저장 규칙을 바꾸지 않는다.

PC 후보 면담(너비 1001px 이상)은 왼쪽에 큰 캐릭터와 작은 면담 정보, 오른쪽에 안내·대사·추천 질문·입력창을 배치한다. 인물 사진은 높이에 맞춰 비율을 유지하며 하단만 잘라 허리 부근까지 표시한다. 너비 1000px 이하에서는 기존 위아래 배치를 유지한다.

1개월차 PC 화면은 운영 메뉴·인물·대화 영역을 나누어 인물이 대화창에 가려지지 않게 표시한다. 너비 1000px 이하에서는 기존 위아래 배치를 유지한다. 영입 결과의 사진은 실제 선발된 신입과 기존 멤버 3명으로 구성하며 시작 화면 단체사진을 재사용하지 않는다. 배경 제거본의 흰 테두리는 프로듀서 수정본을 받으면 교체하며, 현재 원본 자체를 편집하지 않았다.

영입 확정 사진의 여백은 원본 가장자리에서 측정한 사진별 색으로 채운다(`RecruitmentResult.tsx`의 `recruitmentBackgrounds`). 원본 이미지의 색은 수정하지 않는다. 1개월차 PC 인물 확대는 위쪽을 기준으로 하여 정수리가 사진 영역 밖으로 잘리지 않게 한다.

## 파일 구성

캐릭터마다 PNG 4개가 있다. 프로듀서의 파일 구분을 따른다.

| 파일명 | 프로듀서 파일 | 용도 |
|---|---|---|
| `profile.png` | `이름_프로필.png` | 프로필 원본 |
| `profile-2.png` | `이름_프로필2.png` | 두 번째 프로필 원본 |
| `half-body.png` | `이름_상반신.png` | 상반신 원본 |
| `half-body-transparent.png` | `이름_상반신_배경제거.png` | 프로듀서 제공 배경 제거본 |

일부 원본 파일명의 `1.`·`2.` 접두사는 로컬 파일명에서만 정리했다. `manifest.json`에 공유 폴더 안의 정확한 원본 경로와 해상도·SHA-256을 기록했다. 프로듀서가 제공한 투명본을 사용하며 별도로 이미지 생성이나 배경 제거를 수행하지 않는다. 추가 편집이 필요하면 먼저 작업 범위를 확인한다.

## 교체와 갱신

- 이전 Google 문서 추출본을 이번 공유 폴더의 파일로 교체했다. 기존 AI 배경 제거본 14장은 프로젝트에서 삭제했다. 이전 `half-body-waist*`·`half-body-thigh*` 경로는 사용하지 않는다.
- 공유 폴더의 캐릭터 시트·표정 모음·의상·배경은 이번 캐릭터 이미지 묶음에 포함하지 않았다. 필요할 때 같은 공유 폴더에서 확인하고 사용한다.
- 이 디렉터리는 2026-11-04 시점의 로컬 사본이며 자동 동기화되지 않는다. 후속 작업에서는 공유 폴더의 변경을 확인하고 해당 파일과 manifest, 미리보기를 함께 갱신한다.
- 검증: ZIP 무결성, 28개 파일의 원본 바이트 일치, 7개 배경 제거본의 알파 채널, 이전 AI 배경 제거본의 프로젝트 내 제거를 확인했다. 프런트 코드는 수정하지 않았다.
