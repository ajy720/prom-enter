# 캐릭터 이미지

## 2026-11-11 대화 사진 크기 통일 (#32)

PC 세로 배치는 인물 배율을 유지하면서 가슴 아래를 대화창 뒤로 가린다. `usePortraitLayout.ts`가 실제 가로/세로 배치와 헤더·배너·패딩 높이를 측정해 크롭과 화면 하단 정렬을 적용한다. 나레이션과 모바일에는 PC 크롭 규칙을 적용하지 않는다.

기본·표정 PNG 42장의 알파 채널 경계(왼쪽·위·오른쪽·아래)와 원본 너비·높이를 `frontend/src/portraitFrames.ts`에 기록했다. `PhotoSlot`과 `portraits.css`가 투명 여백을 제외한 인물 높이·중앙을 맞춘다. 원본 파일은 편집하지 않는다. 사진 교체 시 Pillow의 `Image.open(path).getchannel('A').getbbox()`와 `image.size`로 해당 경계값도 갱신한다. 백하연만 별도로 확대하던 규칙은 공통 크기로 대체하며, 대사 길이·표정·종료 상태가 표시 높이를 바꾸지 않는다. 화면에 들어가지 않으면 페이지 스크롤을 허용한다.

이미지 기준은 사용자가 직접 제공한 사진이다(2026-11-09 변경). 공유 폴더는 더 이상 조회·사용하지 않는다. 새 사진은 아래 캐릭터 대응에 따라 인물별 폴더에 원본 그대로 저장하고, 용도·첨부 파일명·해상도·SHA-256을 manifest에 기록한다. 기존 사진의 출처 기록은 보존한다.

2026-11-04에 이전 프로듀서 공유 폴더에서 아래 28장을 내려받았으며, 파일 내용은 재압축·크기 변경·색 보정 없이 그대로 보존했다.

2026-11-05에 공유 폴더를 다시 조회하고 배경 제거본·프로필1 각 7장의 SHA-256이 로컬 manifest와 일치함을 확인했다. 백하연 안내·후보 소개·후보 면담·영입 결과·1개월차 대화 인물에는 `half-body-transparent.png`를 사용한다. 사진 경로는 `introContent.ts`의 `characterPortraits`에서 기존 인물 ID에 대응시킨다. 첫 내레이션에는 배경만 표시한다.

기존 멤버 프로필과 후보 면담·최종 선발 목록에는 `characterProfiles`에 기록한 `profile.png`(프로듀서의 프로필1)를 사용한다. 최종 영입 확정 창만 예외로, 선발 신입은 배경이 있는 `half-body.png` 원본, 기존 멤버 3명은 `profile-2.png`를 사용하며 `RecruitmentResult.tsx`의 `recruitmentPhotos`에서 대응시킨다. 서버 화면과 브라우저 데모 모두 같은 사진 대응을 사용한다. 후보 면담의 백하연 사진은 기존 화자 판정에 따라 8회 종료 안내에서만 표시한다. 1개월차는 현재 대사의 화자를 기준으로 신입·리안·도하·세인·백하연 사진을 표시하며, 훈련·규칙 선택만으로 대화 상대나 사진을 바꾸지 않는다. 사진 변경으로 면담 횟수·기록·종료·저장 규칙을 바꾸지 않는다.

PC 후보 면담(너비 1001px 이상)은 왼쪽에 큰 캐릭터와 작은 면담 정보, 오른쪽에 안내·대사·추천 질문·입력창을 배치한다. 인물 사진은 높이에 맞춰 비율을 유지하며 하단만 잘라 허리 부근까지 표시한다. 너비 1000px 이하에서는 기존 위아래 배치를 유지한다.

1개월차 PC 화면은 운영 메뉴·인물·대화 영역을 나누어 인물이 대화창에 가려지지 않게 표시한다. 너비 1000px 이하에서는 기존 위아래 배치를 유지한다. 영입 결과의 사진은 실제 선발된 신입과 기존 멤버 3명으로 구성하며 시작 화면 단체사진을 재사용하지 않는다. 대화용 배경 제거본은 2026-11-09에 사용자가 제공한 정방향 기본 PNG로 교체했다. 제공된 파일 자체는 편집하지 않았다.

영입 확정 사진의 여백은 원본 가장자리에서 측정한 사진별 색으로 채운다(`RecruitmentResult.tsx`의 `recruitmentBackgrounds`). 원본 이미지의 색은 수정하지 않는다. 1개월차 PC 인물 확대는 위쪽을 기준으로 하여 정수리가 사진 영역 밖으로 잘리지 않게 한다.

## 파일 구성

2026-11-10 Part 4용 사용자 첨부 `이도/여울/사야_과거논란.png`와 `이도/여울/사야_댓글창.png` 여섯 장을 각 인물 폴더의 `past-rumor.png`·`rumor-comments.png`로 원본 그대로 저장했다. [Part 4 manifest](part4-manifest.json)에 출처 파일명·해상도·SHA-256을 기록했다. `part4Content.ts`의 기존 ID 매핑으로 13개월 글·댓글에만 표시한다. 갱신할 때는 사용자가 새로 제공한 파일을 복사하고 이 별도 manifest를 갱신하며, 기존 인물 사진과 manifest 이력은 유지한다.

캐릭터마다 기본 파일 4개와 추가 표정 5개가 있다. 프로듀서의 파일 구분을 따른다.

| 파일명 | 프로듀서 파일 | 용도 |
|---|---|---|
| `profile.png` | `이름_프로필.png` | 프로필 원본 |
| `profile-2.png` | `이름_프로필2.png` | 두 번째 프로필 원본 |
| `half-body.png` | `이름_상반신.png` | 상반신 원본 |
| `half-body-transparent.png` | `최종사진`의 기본 표정 | 대화용 기본 컷 |
| `expression-{excited,angry,happy,sad,surprised}.png` | `최종사진`의 설렘·화남·기쁨·슬픔·놀람 | 대화용 표정 컷 |

일부 원본 파일명의 `1.`·`2.` 접두사는 로컬 파일명에서만 정리했다. `manifest.json`에 공유 폴더 원본 경로 또는 사용자 첨부 파일명과 해상도·SHA-256을 기록했다. 프로듀서가 제공한 투명본을 사용하며 별도로 이미지 생성이나 배경 제거를 수행하지 않는다. 추가 편집이 필요하면 먼저 작업 범위를 확인한다.

## 교체와 갱신

- 이전 Google 문서 추출본을 이번 공유 폴더의 파일로 교체했다. 기존 AI 배경 제거본 14장은 프로젝트에서 삭제했다. 이전 `half-body-waist*`·`half-body-thigh*` 경로는 사용하지 않는다.
- 이전 공유 폴더의 캐릭터 시트·표정 모음·의상·배경은 이번 캐릭터 이미지 묶음에 포함하지 않았다. 추가 사진이 필요하면 사용자에게 요청한다.
- 프로필·상반신 원본 21장은 2026-11-04 공유 폴더 사본이며, 대화용 배경 제거본 7장은 2026-11-09 사용자 첨부 파일이다. 후속 작업에서는 사용자가 제공한 파일을 인물별로 저장하고 해당 파일과 manifest, 미리보기를 함께 갱신한다.
- 검증: ZIP 무결성, 28개 파일의 원본 바이트 일치, 7개 배경 제거본의 알파 채널, 이전 AI 배경 제거본의 프로젝트 내 제거를 확인했다. 프런트 코드는 수정하지 않았다.

## 2026-11-09 대화용 사진 교체

- 사용자가 직접 전달한 이도·여울·세인·사야·백하연·리안·도하의 `이름_정방향_기본.png` 7장을 기존 `half-body-transparent.png` 경로에 바이트 그대로 복사했다. 모두 1440×1440 RGBA이며 투명 영역을 유지한다. 크기 변경·여백 제거·재압축·색 보정은 하지 않았다.
- 기존 경로를 유지하므로 백하연 안내·후보 소개·후보 면담·영입 안내·1개월차 대화에 적용된다. 프로필과 최종 영입 확정 단체 구성에 쓰는 원본 사진은 유지한다. 다른 화면도 같은 경로를 사용하면 교체본이 표시된다.
- 공유 폴더는 조회를 시도했으나 접속 오류로 최신 파일을 확인하지 못했다. 이번 교체의 기준은 사용자 첨부 파일이며, manifest의 해당 항목에 첨부 파일명·갱신일·해상도·SHA-256을 기록했다. 로컬 Downloads 경로는 다른 개발자의 환경에 의존하므로 기록하지 않는다.
- 검증: 첨부 7장과 교체 파일의 바이트·SHA-256 일치, 알파 채널, manifest 전체 28장의 경로·해상도·해시를 확인했다. 전체 미리보기도 교체본으로 갱신했다.

## 2026-11-09 2개월차 사진 연결

- 기존 사용자 제공 `half-body-transparent.png` 7장을 재사용한다. 백하연 안내·면담 종료 안내·센터 결정 대화에는 백하연, 멤버 면담에는 서버가 확정한 상대의 사진을 표시한다. 신입은 선발 결과의 기존 ID·profile_id를 사용한다.
- 원본 파일과 공통 사진 매핑은 유지하고 2개월차에만 표시 배율·하단 기준점을 적용한다. 3개월차 이후의 이미지·배치는 바꾸지 않는다. 면담 횟수·센터 판정·저장·복원 형식도 유지한다.

## 2026-11-09 1개월차 사진 배치 보완

- 1개월차 시작 안내의 백하연 임시 이미지를 기존 사용자 제공 사진으로 연결했다. 본 화면 인물은 원본 비율·색과 윤곽 그림자를 유지하며, 하단 경계를 PC 화면 끝 또는 모바일 대사창 뒤에 배치한다. 서버 화면과 브라우저 데모에 같은 전용 스타일을 적용한다.
- 1·2개월차의 인물 있는 장면은 배경 검정 레이어를 50%로 통일하고, 인물 없는 나레이션은 원본 연습실 배경만 표시한다. 월 진행·훈련·면담·센터 선택·저장 형식은 바꾸지 않는다.

## 2026-11-09 Part 1 사진 규칙 정리

- 도입·호칭 입력·복도 안내·후보 소개·후보 면담·영입 후 안내의 정사각 대화용 사진은 공통 배율과 하단 기준점을 사용한다. 인물 하단은 대사창 뒤 또는 화면 끝에 가리며 얼굴·머리·어깨는 유지한다. 면담 마지막 답변에서 백하연 종료 안내로 바뀌어도 같은 크기 규칙을 따른다.
- 후보 목록·최종 선발 목록과 기존 멤버 프로필은 기존 `profile.png`를 contain으로 표시한다. 영입 확정의 실제 선발 신입 `half-body.png`·기존 멤버 `profile-2.png`와 시작 단체사진의 용도는 유지한다. 원본 이미지 파일과 인물 ID·면담·영입·저장 규칙은 변경하지 않았다.

백하연의 대화용 투명 사진은 대화창이 바로 아래인 세로 배치에서만 가슴 아래까지만 보이도록 CSS에서 확대한다. 왼쪽 인물·오른쪽 대화창의 가로 배치는 기존 골반 구도를 유지한다. Part 1·1개월차·2개월차 각각의 반응형 배치 전환 시점에 맞추고 얼굴·머리·어깨를 보존한다. 원본 PNG와 다른 인물의 배율은 유지한다.

## 대사별 표정

- 다운로드 폴더의 `최종사진`에서 7명 × 6종을 원본 바이트 그대로 복사했다. 기본 표정은 기존 `half-body-transparent.png` 경로에 둔다.
- 서버가 보낸 현재 대사의 화자 ID와 `expression`으로 사진을 고른다. 이전 기록이나 고정 안내처럼 표정 값이 없거나 해당 파일을 불러오지 못하면 같은 인물의 기본 컷을 사용한다.
