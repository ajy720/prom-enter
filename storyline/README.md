# Prom::Enter 스토리라인

프로듀서가 작성한 [Figma `prom::enter`](https://www.figma.com/design/zvPBVmlcjPJzgtgfB6QXFg/prom--enter?node-id=0-1)의 스토리 초안을 읽기 쉬운 Markdown으로 정리한 자료다. **확인 기준일은 2026-11-02(Asia/Seoul)**이며, 원문 수집은 11월 1~2일에 진행했다.

이 문서는 스토리 자료이며 실행 가능한 게임 규칙 파일이 아니다. `backend/app/content/demo.json`의 1 → 6 → 13 → 24개월 축약 데모와도 구분한다. 이 문서를 추가하면서 게임 코드나 예시 판정식을 변경하지 않았다.

2026-11-03에 개발 측에서 정한 [최소 구현 기획 결정](06-minimal-decisions.md)은 당시 축약 구현의 기준이다. 현재 18~21개월차 국내·해외 분기는 [월별 사건](02-monthly-events.md#18개월차--해외-현지-제안과-사전-검증)과 [Part 4 구현 기준](../docs/development/part4-server-integration-rules.md)을 참고한다.

## 읽는 기준

- **원문**: Figma에서 실제로 읽은 문구. `sources/`에서 오탈자와 미완성 표현도 보존한다.
- **정리**: 긴 문장을 상황·과제·판정·결과로 구분한 표현. 분기 조건을 새로 만들지 않는다.
- **확인 필요**: 원문만으로 정확히 결정할 수 없는 사항. 편의상 임계값이나 결과를 채우지 않는다.
- 월별 문서의 출처 `S001` 등의 링크는 로컬 원문 추출 항목이다. 검색 중 주소 갱신 지연이 관찰되어 미검증된 개별 Figma 노드 주소는 제공하지 않는다. 원문 JSON의 검색어와 결과 순번으로 Figma에서 다시 찾을 수 있다.

## 전체 흐름

회사와 대표 소개 → 비서 안내 → 후보 3명 면담 → 신입 1명 선발 → 4인조 프로뮤 결성 → 데뷔 준비와 쇼케이스 → 국내 활동·광고·예능 → 과거 논란 조사 → 이미지 회복과 팬미팅 → 일본 프로모션 제안 → 해외 진출 또는 국내 잔류 → 단독 콘서트 → 계약 전 마지막 컴백 → 시상식·계약 결산 → 최종 결말.

이 흐름은 원문 제목과 본문을 월순으로 정리한 것이다. 연결선 전체를 기계적으로 추출한 그래프가 아니며, 특히 조기 종료와 같은 달의 복수 경로는 추가 확인이 필요하다.

## 수치 표기

| 원문 약어 | 정리본 표기 |
|---|---|
| 팀 | 팀워크 |
| 피 | 피로도 |
| 인 | 인지도 |
| 팬 | 팬 수 또는 팬덤 |
| 자금·수익 | 원문의 경제 수치. 두 값의 관계는 미확정 |
| 신입 신뢰도 | 선택한 신입과 대표의 관계 수치 |
| 능력치·선택 분야 | 보컬·댄스·비주얼·예능 등. 대상/범위가 생략된 경우 그대로 표시 |

`+`만 있고 변화량이 없는 항목은 숫자를 추정하지 않았다. `피 0`처럼 변화량인지 절대값인지 불명확한 표기도 별도로 확인한다.

## 원문 수집 범위

로그인한 인앱 브라우저에서 Find 검색 결과와 접근성 텍스트를 읽었다. 도입·면담·월별 사건 본문·논란 사실관계·최종 결말·작성 가이드를 수집했고, 월별 제목 34개는 복수 경로를 포함한다. 이미지·댓글·연결선 전체·숨겨진 모든 레이어를 포함한 완전한 `.fig` 백업은 아니다. 문장 줄바꿈과 시각적 배치는 원본과 다를 수 있다.

Figma 초안과 이 정리본이 달라지면 최신 Figma를 다시 확인하고 수집일을 갱신한다. 모호한 조건을 확정한 뒤 실제 게임 데이터와 판정 코드를 별도로 수정한다.
